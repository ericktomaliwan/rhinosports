# RhinoSports

[![Website](https://img.shields.io/badge/Visit-Website-brightgreen)](https://rhinoshirtsph.com/)

A modern sports apparel and teamwear platform, powering the digital storefront and customization experience of [RhinoShirts PH](https://rhinoshirtsph.com/).

## About

**RhinoSports** is the codebase behind RhinoShirts PH, an innovative provider of custom sportswear and uniforms in the Philippines. The platform blends advanced web technologies with robust backend systems to offer product customization, team shop capabilities, and a seamless online ordering experience.

- **Live website:** [https://rhinoshirtsph.com/](https://rhinoshirtsph.com/)

## Features

- Custom sportswear builder and product personalization
- Easy team store and group order management
- Responsive storefront for desktop and mobile users
- Secure and scalable architecture for high transaction volumes
- Built with PHP, JavaScript, and modern CSS frameworks

## Tech Stack

| Language     | Usage                            |
|--------------|----------------------------------|
| PHP          | Core backend and server logic    |
| JavaScript   | Interactive UI, builder, logic   |
| CSS / SCSS   | Styling, responsive layout       |
| Handlebars   | Templating in UI components      |
| Blade        | PHP templating in rendering      |

## Getting Started

1. **Clone the Repository**
2. **Install Dependencies**
- Ensure you have PHP and Composer installed.
- For JavaScript dependencies, use npm or yarn.
3. **Environment Setup**
- Copy `.env.example` to `.env` and adjust settings for your environment.
4. **Run Development Server**
- Start the PHP server and local asset bundler as required by your setup.
